# Скиллы для агентов

`android-design` — сторонний скилл для проектирования нативного Android UI:
Material 3 / M3 Expressive, Compose, edge-to-edge, адаптивность, доступность.
Источник: npm `android-design@1.0.0` (https://github.com/allexp1/android-design),
лицензия MIT (см. `android-design/LICENSE` и `NOTICE`). Установлен в
`~/.agents/skills/android-design`, поэтому доступен всем агентам на хосте.

Правило: перед правками UI сверяться с `references/quality.md` и
`references/components.md` этого скилла, а не «на глаз».
